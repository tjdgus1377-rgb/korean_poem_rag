# 시담 한국 근대시 100편 데이터

2026-10-22 기준. 개화기부터 일제강점기 사이에 창작된 시 100편의 식별 정보, 전문, 작품별 해석 근거를 연결한다.

## 파일과 연결 키

| 파일 | 내용 |
| --- | --- |
| `poems_metadata.csv` | `id`, `title`, `author`, `publication_year`, 메타데이터·전문 출처 URL만 보존 |
| `poems_text.jsonl` | 각 `id`의 시 전문. 원문 출처의 옛 표기와 판본상 표현을 가급적 유지 |
| `commentary_sources.csv` | 작품 해설, 학술 연구, 백과 항목의 출처와 접근 범위 |
| `poem_commentary_map.csv` | 작품 `id`와 근거 자료 `source_id`의 연결 |
| `evidence_notes.jsonl` | 근거의 위치, 접근 상태, 작품 해석 요약 |
| `author_context_notes.jsonl` | 시인별 확인된 생애·시세계 맥락, 작품 구절에 연결하는 방법과 해석 시 주의점 |
| `interpretation_readiness.csv` | 100편별 대표 근거와 답변 가능 범위의 자료 검토 결과 |
| `question_coverage_review.csv` | 실제 구절 질문을 예로 든 작품별 종합 해석 가능성 검토. 아직 검토하지 않은 작품은 `검토 대기`로 표시 |
| `interpretation_examples.jsonl` | 원문의 구절·질문·출처에 근거한 답변·작가 맥락의 연결·한계를 기록한 작성 예시. 외부 근거가 아님 |
| `text_source_review.jsonl` | 표시한 공개 전문 출처와의 대조 기록·해시·자동 및 수동 확인 범위. 초판 정확성 인증은 아님 |
| `curation_assessment.json` | 주요 구절 감상 자료의 문헌 검토 판정과 대상 파일 해시. 자료 변경 시 재검토 필요 |
| `interpretation_assessment.md` | 최종 자료 적합성 판단·검토 범위·남은 한계 |
| `research_status.json` | 실제 레코드 수, 예시 검토가 남은 작품 ID, 단일 해석 자료 작품, 남은 작업 |

`id`는 작품을 연결하는 내부 키다. 제목이 같아도 작가가 다른 작품은 별도로 기록한다. 김영랑 「끝없는 강물이 흐르네」와 초출 제목 「동백닢에 빛나는 마음」은 같은 작품으로 한 번만 센다.

`publication_year`는 출처에서 확인되는 공표 또는 수록 시집의 간행 연도다. 창작 연도와 같다고 가정하지 않는다. 심훈 「그날이 오면」은 1930년 3·1절에 썼지만 검열로 1932년 시집 발간이 좌절되어 1949년 유고 시집에 실렸다. 따라서 메타데이터에는 1949년을 적고, 창작 시기의 근거는 해설 노트에 따로 보존한다. 윤동주 「눈 오는 지도」도 본문에 1941년 3월 12일이 적혀 있지만 수록 시집 연도는 1948년이다. 모르는 연도는 빈칸으로 둔다.

전문 출처는 작품마다 다르며 `text_source_url`에 기록한다. 위키문헌, 시한잔, 공유마당 및 그 밖의 공개 원문을 대조했다. 해설 자료의 저작권·접근 조건은 시 전문과 별개다. 학술 논문은 공개 초록 또는 실제 확인한 공개 PDF의 범위를 `locator`와 `access_status`에 구분했다. 도서관의 책 소개·발췌문을 읽은 경우에도 책 전문을 읽은 것으로 취급하지 않는다.

## 작품 교체와 데이터 일관성

해설이 작품의 일부 이미지에만 닿거나 작품별 자료가 부족한 경우, 같은 시기 작품 중 전문과 구체적 해설을 확인한 작품으로 교체했다. 최근 교체에는 이상 「가정」, 한용운 「수(繡)의 비밀」, 김영랑 「청명」, 심훈 「그날이 오면」, 김소월 「길」이 포함된다. 앞선 교체의 새 작품에는 김소월 「초혼」·「접동새」·「산유화」·「바라건대는 우리에게 우리의 보습 대일 땅이 있었더면」, 이장희 「봄은 고양이로다」, 홍사용 「나는 왕이로소이다」, 김영랑 「거문고」, 한용운 「나의 꿈」이 포함된다.

## RAG 사용 기준

사용자가 특정 구절의 뜻을 묻는다면 해당 시 전문, `poem_id`에 연결된 작품별 노트, 같은 시인의 `author_context_notes.jsonl`을 함께 검색한다. 작품의 표현과 구조를 먼저 읽고, 시인의 생애·시세계·시대 배경이 그 독법을 어떻게 뒷받침하는지 설명한다. 작품별 노트가 그 구절 자체를 다루지 않으면 자료를 종합한 가능한 해석이라고 밝힌다. 작가 일반론만으로 그 구절의 뜻 또는 시인의 실제 의도를 확정하지 않는다. 서로 다른 연구 관점은 출처별 견해로 제시한다.

작가 맥락 노트는 12명에 대해 1건씩 정리했으며 100편 모두에 같은 시인의 자료를 연결했다. 이 12건은 작품 해석 노트 수에 포함하지 않는다. 구절 질문 대응 가능성은 근거 건수가 아니라 작품 원문·작품 해설·작가 맥락을 종합한 실제 답변으로 평가해야 한다.

`interpretation_readiness.csv`는 자료 검토 결과다. 실제 챗봇 응답을 질문별로 평가한 결과는 아니다.

`question_coverage_review.csv`는 시 전문·작품 해설·시인 맥락을 함께 읽어 구절 질문을 평가하는 별도 기록이다. 2026-10-22 현재 100편 모두 대표 질문을 검토했다. `핵심 질문 설명 가능`은 기록된 대표 질문과 연결된 근거 노트를 바탕으로 한 검토 판단이다. 작품의 모든 구절이나 실제 챗봇 응답의 정확성을 보증하지 않으며, 자료에 없는 창작 의도는 단정하지 않는다.

## 2026-10-22 추가 정합성 확인

정지용 「바다2」의 본문과 해설이 서로 다른 동명 시편에 속한 문제를 발견하여, 구체적 해설이 풍부한 1935년 ‘바다는 뿔뿔이’ 시편으로 본문·ID·출처를 통일했다. 「노정기」의 교육 해설 요약에 섞여 있던 비교 작품의 공장·청춘 설명도 제외했다. 교체 이전 자료는 `archive/`에 변경 이유와 함께 보존하며, 이 폴더는 RAG 색인 대상에서 제외한다.

김소월 「꿈」은 동명인 6행·2행 작품이 한 본문으로 합쳐져 있어, 국립국어원에서 직접 해설한 2행 「꿈2」로 통일하고 내부 ID를 `WS_SOWOL_DREAM_2`로 변경했다. 「못 잊어」의 1925년은 출처에서 확인한 수록 시집 연도이며 최초 발표 연도로 단정하지 않는다.

`interpretation_examples.jsonl`은 현재 100편에 각각 대표 질문 한 건씩 작성했다. `source_based_answer`는 연결한 노트에 근거한 설명, `contextual_synthesis`는 시인 맥락을 덧붙인 종합, `interpretive_limit`는 남겨 둘 불확실성을 뜻한다. 이 파일을 외부 근거 자료로 재색인하면 생성한 설명을 원출처처럼 순환 인용할 수 있으므로 **외부 근거 색인 대상에서 제외**한다. 실제 RAG 실행 결과나 전체 질문 대응률로 취급하지 않는다.

`python3 scripts/refresh_commentary_index.py`는 준비도·작품 연결의 근거 수·현황 JSON·해설 README 집계를 갱신한다. 원문과 외부 근거 자체는 바꾸지 않는다.

`python3 scripts/audit_corpus.py`는 100편의 ID·작가·제목, 전문 존재 여부, 노트·출처·작가 맥락·평가표의 참조 관계와 해석 근거 집계의 일치를 점검한다. 이 점검은 내용 해석의 충분성이나 모든 원문의 완결성을 자동으로 증명하지 않는다.

## 재개 후 구절·전문 확인

「해당화」의 귀환 약속은 꽃이 **피기 전**이다. 「나의 침실로」는 신성화된 사랑이라는 백과 독법과 자유연애·사회 관습이라는 학술 독법을 나누어 보존한다. 「초가」의 EBS 해설은 공개 재게시본 15–18쪽을 화면으로 읽은 기록이며 공식 호스팅 URL로 오인하지 않는다.

한용운 「사랑하는 까닭」·「거짓 이별」·「수의 비밀」은 현대어 전사를 표시한 위키문헌의 해당 원문 표기로 통일했다. 「나의 꿈」의 빠진 표현을 복원했고, 「1933, 6, 1」의 ‘천평’은 공개 학술논문이 전집을 인용한 ‘天秤’에 근거해 ‘천칭(天秤)’으로 교정했다. 해당 작품의 나머지 전사는 시한잔 판본을 따른다. 변경 전 전문과 예시는 `archive/20261022_declared_text_alignment.json`에 있다.

`question_coverage_review.csv`의 `reviewed_interpretation_topics`는 원문·노트로 설명할 수 있는 주요 해석 영역이다. 각 영역을 모두 실제 챗봇으로 시험했다는 뜻은 아니다. `answer_example_id`가 지정 답변에 연결되며 `scope_limit`는 그 설명에서 지켜야 하는 경계이다.

모든 작품별 근거 노트의 `evidence_role`을 명시했다. 외부 근거 색인에는 `interpretation`과 `context_only`를 역할을 구분하여 넣고, `access_lead`는 아직 읽지 않은 자료의 탐색 경로로만 보관한다. `interpretation_examples.jsonl`, `question_coverage_review.csv`, `curation_assessment.json`, 이 검토 보고서와 `archive/`는 외부 근거로 재색인하지 않는다.
