# 시담 100편 해석 자료 적합성 검토

2026-10-22. 판정 대상은 현재 활성화된 시 100편이다.

## 판정

**주요 구절의 의미를 시 원문·작품 해설·시인의 확인된 배경과 연결해 설명하는 감상 대화용 자료로 조건부 적합하다.**

100편의 원문과 노트를 읽고 주요 이미지·상징·시상 전개의 설명 범위를 정리했다. 각 작품에 대해 실제 구절 질문의 답변을 작성하면서, 출처가 말한 해석과 시인 맥락을 보탠 종합을 구분했다. 다시 조사해도 핵심 해석 근거가 좁았던 작품은 교체했다. 이번 문헌 검토에서 작품 전체를 추가 교체해야 할 정도로 핵심 설명이 비어 있는 작품은 남지 않았다고 판단한다.

이 판정은 출처가 두 건이라는 이유나 예시 한 개가 있다는 이유로 내린 점수가 아니다. 작품별 검토 영역과 한계는 `question_coverage_review.csv`, 구체적인 설명은 `interpretation_examples.jsonl`, 실제 외부 근거는 `evidence_notes.jsonl`에 있다. 자료의 깊이는 작품마다 다르다.

## 확인한 범위

| 항목 | 결과 | 증명하는 범위 |
| --- | --- | --- |
| 활성 작품·전문 | 각각 100편 | ID 및 작가·제목의 일관성, 중복 작품 없음 |
| 표시한 전문 출처 대조 | 100편 | 웹 판본과의 일치 또는 확인한 교정·영역 선택 |
| 주요 해석 영역 | 100편 | 이미지·전개·역설 등 설명할 영역을 작품별로 구체화 |
| 작성 답변 예시 | 101건, 100편 | 각 작품 대표 질문 1건, 「초가」 추가 질문 1건 |
| 시인 맥락 | 12명, 100편 연결 | 확인된 생애·시세계와 개별 작품의 연결 |
| 작품별 노트 | 262건 | 해석 217, 맥락 39, 미열람 자료의 접근 경로 6 |
| 출처 목록 | 259개 레코드 | 서지·맥락·본문을 포함한 출처 기록. 모두 독립적인 해석 자료라는 뜻은 아님 |

모든 작성 답변에는 최소 한 건의 작품별 해석 노트가 있으며, 미열람 접근 경로를 해석의 근거로 인용한 예시는 없다. 데이터 참조·전문 해시·예시 구절의 존재 점검도 통과했다.

전문 대조는 완전 일치 75편, 띄어쓰기·문장부호 차이 18편, 수동으로 제목·판본 영역·부기·날짜를 구분한 6편, 학술 인용과 대조해 오자를 교정한 1편이다. 육필·초판 전체를 교감했다는 뜻은 아니다.

## 해석 노트가 한 건인 12편의 판단

개수보다 그 자료가 작품의 주요 표현과 전개를 얼마나 다루는지 확인했다.

| 작품 | 현재 직접 해설이 다루는 핵심 |
| --- | --- |
| 삭주구성 | 공식 평가 해설의 현실·꿈 거리, 높은 산, 새와 구름의 대비 |
| 복종 | 백과의 자발적 헌신, 자유의지, 명령의 거부 |
| 찬송 | 세 연의 비유·반복과 의·자비를 향한 기원 |
| 사랑하는 까닭 | 홍안·백발, 미소·눈물, 건강·죽음의 세 대비 |
| 거짓 이별 | 실제 부재와 거짓이라는 의지, 노화·뜨거운 정서, 마지막 죽음 |
| 나의 꿈 | 별·바람·귀뚜라미와 상황 가정·변신·돌봄의 구조 |
| 보습 대일 땅 | 노동의 꿈·유랑·아득한 희망·두 번째 전환과 전진 |
| 호수1 | 얼굴과 마음의 크기 대비, 눈감기의 역설 |
| 인동차 | 겨울 견딤, 불·무순·풍설, 책력 없는 산중의 인내·탈속 |
| 그의 반 | 고귀하고 먼 그, 여민 손, 바다 이편의 불완전한 자아 |
| 돌담에 속삭이는 햇발 | 문태준의 봄 감각·부드러운 말소리·자연과 마음의 비유 |
| 말세의 희탄 | 백과의 동굴·식민 현실, 하강과 상승, 도취와 인고의 이견 |

이 작품들도 시인 맥락은 별도로 연결된다. 단일 해설의 견해를 유일한 해석으로 고정하지 않는다. 희귀 어휘의 어원, 특정 인물의 신원, 실제 창작 사건까지 이 표가 입증하는 것은 아니다.

## 이번 재개에서 교체·보강한 내용

- 「님의 얼굴」은 편집 요약이 비유의 방향을 흐리고 학술 대목도 제한적이어서 같은 시집의 「논개의 애인이 되어서 그의 묘에」로 교체했다. 메타데이터·전문·출처·노트·검토표를 함께 갱신하고 이전 자료를 보관했다. 앞서 교체한 「비 갠 아침」→「눈 오는 지도」도 문서에 반영했다.
- 「해당화」의 약속을 ‘꽃이 피면’에서 **피기 전**으로 고쳤다. 기다리던 봄을 두려워하는 마음과 꽃이 눈물에 겹치는 장면을 보강했다.
- 「나의 침실로」는 백과의 사랑 신성화 독법과 유재천의 자유연애·사회 관습 독법을 분리했다. 「말세의 희탄」은 인고와 도취라는 이견을 살렸다.
- 「초가」는 EBS 해설로 후반부까지 보강했다. ‘밀고자’인 강물을 마을의 피폐함을 알리는 존재로 풀이한 재게시 교재는 판본 확인 한계를 표시해 보조 근거로만 추가했다.
- 「꽃」의 극한과 미래, 「삭주구성」의 꿈속 거리, 「춘설」의 좋아서 서러운 계절 감각, 「꿈밭에 봄마음」의 이혜원 운율 분석을 구체화했다.
- 표시한 전문 판본에 맞춰 한용운 세 작품의 표기를 통일하고 「나의 꿈」의 빠진 표현을 복원했다. 「1933, 6, 1」의 ‘천평’은 학술논문에 인용된 ‘天秤’을 근거로 ‘천칭(天秤)’으로 교정했다.

## 앱에서 적용할 조건과 다음 단계

1. 해당 작품 전문, `interpretation` 노트, 같은 시인의 맥락을 함께 검색한다. `context_only`는 배경·판본 등 역할을 구분하고, `access_lead`는 읽은 해설처럼 쓰지 않는다.
2. 직접 해설이 없는 표현도 작품과 배경을 연결해 가능한 해석을 설명할 수 있다. 이때 자료를 종합한 추론임을 밝히며 시인의 실제 의도가 확인됐다고 말하지 않는다.
3. 상반된 학술·교육 독법과 판본 차이는 나누어 제시한다. 특정 자연물을 자동으로 조국이나 해방에 대응시키지 않는다.
4. 작성 예시·검토표·이 판정·이전 작품 보관본은 외부 근거로 재색인하지 않는다.
5. 앱 구현 이후에는 별도 질문 묶음으로 검색 결과, 인용, 추론 표시, 답변을 실행 평가한다. **이번 작업에서 실제 RAG 응답 정확도나 모든 구절의 질문 대응률을 측정한 것은 아니다.**
