## 문제

한국 근대시 100편의 수집 자료와 영화 예제 UI 골격은 있으나, PRD 필수 기능을 시담 동작·인수 조건·테스트로 연결한 구현 기준과 작업 규칙이 없다. 기존 README와 활성 데이터 스키마, 발표·시집 간행 연도, 주제 필드, 출처 접근·재이용 범위를 정리해야 한다.
