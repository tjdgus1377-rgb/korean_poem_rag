- universal 해시 잠금 파일로 131개 패키지를 설치했고 `uv pip check`가 호환성을 확인했다.
- 독립 환경에서 전체 테스트 **43 passed / 19.42초**. 실제 GMS를 호출하지 않은 인수 테스트다. uv 설치 외에도 pip의 `--require-hashes` 설치와 `pip check`가 성공했다.
- 재현 기준은 작품 100편 / 공개 근거 문서 343건 / 474청크 / 제외 노트 228건이다. 초기 341청크 이후 실행 중 추가 수집된 공개 문서 6건을 포함해 새 고정 기준으로 만들었다. 생성 답변·개인 검색어·대화는 포함하지 않았다.

- 기존 `README.md` 수집 초안은 `docs/archive/DATA_COLLECTION_README.md`에 그대로 보존하고 현재 앱 재현 안내를 루트 README로 작성했다. 다른 사용자 수정인 `data/README.md`, `requirements.txt`는 이번 변경에 포함하지 않는다.

## 실제 원격 clone 검증

- 원격 `codex/reproducible-setup`을 별도 디렉터리에 실제 `git clone`했다. 로컬 미등록 파일·기존 DB·`.env`는 복사하지 않았다.
- 독립 가상환경에서 clone의 오프라인 매니페스트 검사·배포 파일 검사 성공, 전체 **43 passed / 18.91초**.
- 현재 실제 GMS 키는 자식 프로세스 환경으로만 전달했다. 연락처는 비웠고 대상 폴더의 `.env` 존재는 false다.
- 실제 초기 색인 **100작품/474청크, 17.86초**, 반복 **100/474, 4.58초**. 두 번 모두 DB 본문·출처 지문이 기준과 일치했다.
- 실제 검색 ‘김소월 진달래꽃’ → 진달래꽃. 이별의 정한 질문의 답변에 유효한 근거 번호 5를 확인했고 모든 검색 근거의 poem_id가 선택 작품이었다. 처리 6.41초(근거 검색 0.328초, 생성 6.062초), 임베딩 1536차원, 답변 후 기준 DB 지문도 일치.
- 위 검증은 한 실제 질문과 재현 기준의 확인이며 문학적 해석 전체 정확성의 통과 판정이 아니다.
- 새 clone의 실제 앱을 별도 포트에서 실행하고 브라우저로 검색→작품 선택→질문→인용 출처 펼침을 확인했다. 브라우저 답변은 6.38초, 인용 근거 2건(백과 큐레이션 요약/시 원문)을 표시했다. `screenshots/06-clean-clone-search.png`, `07-clean-clone-answer.png`에 100작품/474청크와 화면을 기록했다. 개인 키·연락처는 화면에 없다.
