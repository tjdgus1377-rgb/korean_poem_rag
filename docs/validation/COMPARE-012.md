# F2015 외부 해설 유무 비교 — ISSUE #12

SPEC `683c490` 이전에 검색137건·답변12건/허용 독법·최소 설명·단정 금지를 고정했다. 이후 공통 입력/외부 누출·작품 격리·권리·조건별 인용의 4개 Red를 확인하고 비교 러너를 구현했다. 전체 **64 passed(10.27초)**, compileall 통과.

같은 gpt-5.4-nano 모델에 양쪽 모두 제목·시인·시 전문을 제공한다. A는 원문만, B는 같은 원문과 실제 검색한 외부 자료만 받는다. 외부 요약·연도 메타데이터·정답·이전 대화는 공통 입력에 넣지 않는다. A/B 순서를 교대하고 같은 공급자 기본 생성 옵션을 사용한다. 정답을 답변 생성에 주입하지 않는다.

실제 실험 결과와 한계는 실행 완료 후 이 보고서에 기록한다. 번호 유효성을 의미 정확성으로 채점하지 않으며 문학적 의미 검토는 에이전트의 근거 대조와 인간 상호 점검을 구분한다.
