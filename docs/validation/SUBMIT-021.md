## 렌더링과 육안 검토

패키지 `render_docx.py`는 이 Windows 환경에 LibreOffice가 없어 실패했다. 별도 숨김 Word 인스턴스로 새 문서만 읽기 전용으로 열어 PDF를 내보낸 뒤, 번들 pypdfium2로 전체 15페이지 PNG를 생성했다. 기존 사용자 파일이나 설치된 LibreOffice를 사용하지 않았다.

모든 페이지를 확인하고 표의 반복 머리글·행 줄바꿈·본문/그림·검은 제목·페이지 번호·하단 여백과 도식 선의 겹침을 점검했다. 불필요한 빈 장과 과도한 마지막 장을 제거했다. 최종 요구사항 6쪽/설계서 9쪽에서 글자 잘림·겹침·누락 글리프를 발견하지 못했다. 이전 육안 확인 후 마지막 문단만 조정한 경우 페이지 PNG 해시를 대조해 바뀐 페이지를 다시 확인했다.

중간 PDF·PNG·생성/검증 스크립트는 Git 제외된 `tmp/submit-qa/` 등에 두고 제출 문서 폴더에는 요청한 3종만 넣었다. 새 앱 테스트나 유료 모델 호출은 수행하지 않았다. 기존 회귀 CI와 독립 문서 리뷰 결과는 PR 댓글에 실제 결과를 기록한다.
