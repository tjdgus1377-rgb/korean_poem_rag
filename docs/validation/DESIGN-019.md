# 문예지 디자인 적용·브라우저 검증

2026-10-23, [ISSUE #19](https://github.com/tjdgus1377-rgb/korean_poem_rag/issues/19), [SPEC](../specs/DESIGN-019.md). 검색·자료·프롬프트·모델·색인 알고리즘은 변경하지 않았다. 실제 역사적 시집의 복제 디자인이 아니라 활자·종이색·괘선·인장 모티브를 사용한 현대적 독서 화면이다.

## 구현과 자동 검증

상단 표지, 검색 지면, 실제 작품의 첫 두 비어 있지 않은 행을 담은 서가 카드, 전문 지면, 대화 영역, 접힌 검색·자료 설정을 구성했다. 독서 중에는 상단 표지를 축약해 작품을 먼저 보여 준다. 시스템 명조/바탕 계열을 사용하고 외부 폰트·이미지·스크립트 요청은 추가하지 않았다. 시 전문은 저장된 텍스트를 이스케이프한 뒤 `pre-wrap`으로 표시한다.

SPEC 최초 커밋 `f38cdcc` 후 HTML 지면의 제목·저자·전문에 스크립트/이미지 삽입 반례를 작성했다. 이스케이프하지 않은 최초 렌더러에서 세 사례 모두 태그가 해석되어 실패(Red 3건)했고, 이스케이프 후 통과했다. 줄바꿈·빈 줄과 원래 텍스트가 파싱 후 보존되는 것도 확인했다. 기존 AppTest는 전문의 새 HTML 표시 경로에 맞춰 작품 제목뿐 아니라 실제 첫 구절도 확인한다. 없는 키·없는 색인의 안내와 비활성화된 채팅, 작품 전환을 유지한다.

- 전체 오프라인 테스트: **67개 통과, 10.13초**. 실제 GMS 호출을 CI 테스트에 넣지 않는다.
- Python 컴파일: 통과. 기존 재현 기준 검사: 작품 100편·문서 343건·근거 청크 474건·제외 자료 228건으로 통과.
- 재현 기준과 사용 중인 로컬 DB의 추가 수집분은 별개다. 화면에 표시된 현재 로컬 DB는 543청크였으며 이를 고정 기준 474청크로 바꾸어 보고하지 않는다.

## 실제 브라우저 결과

잠금 의존성 Python 3.12 환경에서 Streamlit을 실행하고 인앱 브라우저로 직접 조작했다. 데스크톱 1280×720, 모바일 390×844에서 확인했다. 검증용 화면 크기 변경은 종료 전에 해제한다.

| SPEC 조건 | 결과와 실제 확인 |
| --- | --- |
| AC-D1 | 통과. 서비스 표지·검색 입력·서가 카드 확인. 진달래꽃 카드의 읽기 버튼으로 독서 탭·작품 선택이 함께 변경된다. |
| AC-D2 | 통과. 진달래꽃 전문·줄바꿈·원문 링크, 최초 발표 1922/시집 간행 1925 구분. 그날이 오면은 최초 발표 미확인/간행 1949/창작 1930으로 표시한다. 긴 전문은 지면 안에서 스크롤할 수 있다. |
| AC-D3 | 통과. ‘김소월 진달래꽃’은 1편, ‘1922년에 처음 발표된 시’는 진달래꽃·엄마야 누나야 2편, 2099년 조건은 0편·안내를 표시했다. 실제 해설·구절 카드와 과거 답변/근거를 확인했다. 키·색인 없음은 AppTest로 확인했다. |
| AC-D4 | 확인 범위 통과. 두 크기의 페이지 가로 폭은 각각 1280/390으로 viewport와 일치했다. 모바일 전문 가로 스크롤 폭과 표시 폭은 모두 304px, 한 열로 표시된다. 모바일에서 서가를 다시 열고 설정·MMR을 선택했다. Tab으로 조건 검색 버튼에 이동했을 때 2px 인주색 실선 포커스를 확인했다. |
| AC-D5 | 통과. 외부 문자열 이스케이프·줄바꿈 보존 테스트 3건과 템플릿/CSS 검토. 추가 외부 자원 URL 없음. |

실제 질문 ‘진달래꽃을 길에 뿌리는 표현은 어떻게 해석할 수 있나요?’는 8.48초에 답변을 표시했고 실제 인용 근거 3건(작품 메타데이터·시 전문·한국민족문화대백과 요약)의 원문 링크/접근 범위를 펼쳐 확인했다. ‘죽어도 아니 눈물 흘리우리다’ 구절 카드는 8.33초에 표현·가능한 해석·배경·근거와 한계 및 인용 근거 2건을 표시했다. 이는 화면 경로의 실연결 확인이며 전체 문학 해석 품질·성능 개선을 판정한 결과가 아니다.

MMR로 옵션을 바꿔도 과거 두 답변의 `similarity` 표시와 근거 3건/2건은 유지되었다. 그날이 오면으로 옮기면 대화가 0건이었고, 진달래꽃으로 돌아오면 기존 질문·답변 4개와 과거 출처/검색 방식이 복원되었다. 새로운 질문의 MMR 알고리즘 자체는 기존 MMR-011 검증 범위다.

주요 단색 조합의 대비 비율은 먹색/종이색 12.41:1, 보조 글자/사이드바 4.71:1, 인주색/종이색 6.80:1, 흰 글자/인주색 버튼 7.66:1이다. 실제 보조 글자 계산 색상 `rgb(98,102,93)`도 확인했다. 모든 브라우저·운영체제 폰트·보조공학에 대한 인증을 뜻하지 않는다. 설치된 폰트에 따라 자형과 줄바꿈은 달라질 수 있다.
