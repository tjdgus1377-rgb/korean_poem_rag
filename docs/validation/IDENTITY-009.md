# 작품 식별 검증 — ISSUE #9

SPEC 선행 `e0ce465` 후 3 failed를 확인했다. 표기/검색 미구현 2건과 실제 기존 WikiAdapter의 정상 ‘서시’ 본문 거부 1건이다. 환경 오류가 아니다. NFKC의 호환 한자 `琉`→`琉` 기대값을 명시하고 숫자 판본 구분을 검증했다.

수정 후 한자·본명·오탈자·줄임말·구절·부분 제목·동명/다른 작가·다른 판본 반례를 검증했다. 정확 경로는 모델/임베딩 호출 없이 결과를 반환하는 서비스 테스트를 추가했다. 공개 검색 세트의 정확 제목·시인 100건은 모두 정답 ID를 반환했다. 의미 검색 전체137건의 품질 통과를 뜻하지 않는다.

별칭 파일을 재현 입력에 명시 추가했다. 기존 입력·설정·본문 지문·100작품/343문서/474청크/제외228건은 그대로임을 비교 후 매니페스트를 갱신했다. 실제 GMS 질문 smoke는 6.19초(검색 .922초·생성5.266초), 근거 poem_id 일치·1536차원·기준 색인 일치를 확인했다. 정상 위키 본문의 한자 대응은 고정 HTTP 반례로 확인했으며, 이번에 위키 실시간 본문을 새로 수집한 것으로 기록하지 않는다.
