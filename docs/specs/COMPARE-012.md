# F2015 외부 해설 추가 효과 비교 — ISSUE #12

PRD F2015(10·17·19쪽), 대표 질문 최소5개. BENCH-008의 고정 검색137건·답변12건과 지표/복수 해석 기준을 먼저 커밋·검증했다. 데이터 해시/수정 이력은 BENCH-008 검증 보고서를 따른다.

## 비교 계약

사용자 결정: 두 조건 모두 같은 작품 제목·시인·시 전문을 제공한다. A=`without_external`(원문만), B=`with_external`(같은 원문+선택 작품의 검색된 외부 해설/맥락). 이 실험의 RAG 미사용은 ‘외부 해설 미사용’이며 모델 사전학습 지식이 제거되는 실험은 아니다.

같은 모델 인스턴스·질문·시 전문·생성 프롬프트·인용 검증·생성 옵션을 사용하고 대화 이력은 양쪽 모두 비운다. 현재 모델 기본 생성 옵션(temperature/seed 미지정·공급자 기본값)을 동일하게 쓰며 결정적 출력을 주장하지 않는다. A/B 순서는 질문별로 교대해 기록한다. 검색은 기본 similarity를 사용하며 MMR 실험은 별도 선택값으로 명시한다.

공통 입력에는 주제 요약·연도 등 외부에서 얻은 작품 메타데이터를 넣지 않는다. 전문은 허용된 원문 문서 전체를 같은 [근거1]로 제공한다. B는 실제 retrieve의 metadata/poem_text를 제외한 외부 문서만 추가한다. 외부 근거가 없으면 B에도 억지로 골드를 주입하지 않고 0건으로 기록한다. 다른 작품 poem_id·권리 미확인 외부 자료는 생성 전에 거부한다. A는 B의 근거/인용 번호로 검증하지 않는다.

정답 source ID·최소 설명·허용 해석·금지 단정·보고서를 모델/색인에 전달하지 않는다. 새 수집·재색인을 비교 중 수행하지 않는다. 기준 매니페스트·실제 DB 지문과 데이터 해시·모델·옵션·검색 설정·prompt 버전·순서·단계 시간·답변·실제 인용을 기록한다. 개인 질문으로 고정 세트를 자동 갱신하지 않는다.

## 평가·출력

`scripts/evaluate_sidam.py`는 고정137검색/12질문을 실행하며 `--search-only`와 `--answers-only`를 지원한다. 답변 비교 실행은 최소5질문, 현재 기본12개다. 실행 산출물은 `evaluation/runs/`(Git 제외)에 저장하고 공개 검증 문서에는 고정 공개 사례의 결과와 사용한 출처/이용 범위만 선별한다. 키·연락처·로컬 개인 대화·전체 프롬프트를 게시하지 않는다.

검색: 작품 Recall@1/5/10·MRR, 명시 필터 정확성, 빈 골드 처리, 단계별 시간. 답변: BENCH-008의 근거 충실성·인용 정확성·충분성·부족 처리 각0/1/2와 이유/위치. 문학적 복수 해석과 단정 금지를 실제 읽고 대조한다. 자동 인용 번호 검증은 의미 채점으로 변환하지 않는다. 미검토는 null. 에이전트의 근거 대조 검토는 인간/교육생의 상호 점검과 구분한다.

## 인수 조건

AC-C1: A/B 프롬프트의 공통 전문·제목·시인·질문·생성 조건이 같고 A에 외부 요약/연도·골드가 유입되지 않는 테스트.

AC-C2: B의 다른 작품·미허용 근거 거부, B에서 원문 중복/metadata 제외, A/B 각각의 인용 검증·부족 처리·독립 이력 보장.

AC-C3: 실제 같은 모델의 대표12질문24응답과 검색137사례를 실행하고 결과·실패/미확인·한계를 공개 문서에 남긴다. 응답 오류는 숨기거나 정답을 주입해 통과시키지 않는다. 품질 개선이 없거나 역효과여도 그대로 기록한다.
