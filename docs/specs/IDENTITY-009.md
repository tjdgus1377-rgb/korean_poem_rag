# 작품 식별·표기 대응 — ISSUE #9

관련 F2001/F2003/F2004/F2011. 기존 `core_title`은 괄호 밖만 남겨 ‘病院 (병원)’의 한글 입력을 잃으며, 본문 저자 관계식은 원래 제목의 한자까지 요구하여 ‘서시(序詩)’→위키 제목 ‘서시’의 정상 연결을 거부할 수 있다. 이를 고정 반례로 확인하고 수정한다. 미재현 장애를 실제 서비스 발생 사실로 적지 않는다.

## 식별 계약

- 활성 poem_id·원래 제목·판본은 보존한다. 공백/NFKC를 정규화하고 괄호 안의 대응 한글/한자를 검색 표기로 파생하되 바깥 숫자는 반드시 보존한다. 유리창1/바다2/시 제1호를 다른 번호와 합치지 않는다.
- `data/curation/search_aliases.json`은 출처가 확인된 시인 본명(김해경→이상, 김정식→김소월), 명시적인 사용자 입력 힌트(별헤밤/빼들봄)를 별도 유형으로 보관한다. 힌트를 역사적 작품 이칭으로 표시하지 않는다. 확인된 역사적 이칭은 아직 없다.
- 정확 제목·시인/본명·표기·고유 구절·부분 제목은 결정적 검색을 우선한다. ‘길’처럼 동명 작품은 모두 보여 주고 선택하게 한다. 원문 구절 탐색은 임베딩용 주제 데이터에 전문을 억지로 혼합하지 않고 저장된 원문과 대조한다.
- 오탈자는 작가가 명시되고 제목 질의 전체의 정규화 편집거리가 1 이하이며 길이 4자 이상인 경우 후보를 제시한다. 외부 문서 자동 연결에는 퍼지 매칭·줄임말을 사용하지 않는다. 모호한 후보는 사용자 선택 목록으로 유지한다. 자연어 주제/연도는 기존 조건 추출·엄격 필터를 사용한다. 정확 경로로 처리할 수 없으면 기존 의미 검색을 사용한다.
- 외부 문서 강제 포함은 정규 표기/한자 표기 교집합과 본문 첫 정의 문장의 해당 저자 관계가 모두 확인되어야 한다. 다른 저자 이름 뒤에 선택 시인이 언급되는 문서는 거부한다. 작가 일반 문서는 작품 자체 문서로 승격하지 않는다. 교차 작품 poem_id 필터는 유지한다.
- 괄호 한자는 바로 앞의 대응 한글 단어를 치환한 전체 제목으로만 파생한다. ‘또다른고향(故鄕)’의 대응은 ‘또다른故鄕’이며 ‘故鄕’ 단독을 작품 이칭으로 만들지 않는다. ‘나룻배와 행인(行人)’도 동일하다. 전체 제목이 다른 시 작품의 정의 문서는 context_only로 우회 연결하지 않는다.
- 검색 별칭은 별도 참조이고 작품 검색/근거 텍스트를 바꾸지 않는다. 재현 입력 목록에 별칭 파일을 추가하고 입력 해시만 명시 갱신한다. 100작품/343문서/474청크와 본문 지문은 보존한다.

## 인수 조건

AC-I1: 서시/序詩, 병원/病院, 유리창1/琉璃窓1을 처리하며 유리창2와 구분한다. ‘길’은 두 시인, 작가 지정은 해당 작품만 반환한다.

AC-I2: 본명·입력 힌트·공백·실제 원문 구절·부분 제목을 처리한다. 제한된 오탈자 후보를 반환하되 모르는 제목/다른 판본은 정확 검색으로 통과시키지 않는다.

AC-I3: ‘서시는 윤동주가 지은 시이다’의 정상 본문을 허용하고 ‘서시는 김철수가 쓴 시이다. 윤동주…’는 거부한다. 정의 문장이 모호하면 자동 작품 연결을 보류한다.

SPEC 커밋→정상/반례 실패→구현→고정 검색 세트와 회귀 검증→실제 브라우저→PR/CI/리뷰 순서다. 문학 해석의 정답을 추가하거나 미확인 연도를 채우지 않는다.
