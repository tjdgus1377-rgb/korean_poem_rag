# 검색·답변 벤치마크 v1 — ISSUE #8

관련: F2015 준비, F2001/F2006~F2008/F2011, NF2001. 평가 결과 생성 전에 데이터와 이 계약을 먼저 커밋한다. E2E 기준선은 #7, 자료 결손은 #4로 별도 관리한다.

## 고정 데이터와 의미

`evaluation/search_v1.jsonl`에는 활성 100편 각각의 정확 제목·시인 질문과 부분 제목·실제 구절·띄어쓰기·오탈자·한자·확인된 본명·예상 줄임말·연도/범위·주제·동명/판본·없는 작품 사례를 둔다. `gold_poem_ids`는 실제 활성 ID만 사용한다. 동명 ‘길’은 김소월/윤동주 두 작품을 정답으로 보존한다. 제목의 숫자는 판본 구분에 보존한다. 줄임말은 사용자 검색 예시이며 역사적 이칭이라고 주장하지 않는다. 본명은 실제 확보한 근거 위치를 기록한다. 오탈자는 작품명 자체를 변경하지 않는다.

`evaluation/answers_v1.jsonl`은 5개 이상의 대표 질문에 poem_id, question, gold_source_ids, minimum_points, allowed_interpretations, forbidden_claims, expected_abstention, provenance를 둔다. 정답 문장을 고정하지 않는다. 원문에 근거한 복수 독법을 허용하되 시인의 실제 의도·창작 동기·미확인 연도를 단정하지 않는다. 정답 근거는 이용 범위가 확인된 실제 문서 ID와 선택 작품 연결을 검증한다. 외부 해설 효과 비교 사례와 원문만으로 답할 수 있는 사례, 확인 불가 사례를 구분한다.

정답 자료는 검색·생성 프롬프트에 전달하지 않는다. 데이터는 개발용 공개 평가 세트이므로 독립 비공개 테스트로 주장하지 않는다. 해시·버전 변경 없이 질문/정답을 결과에 맞춰 수정하지 않는다. 골드 판정 근거는 기존 메타데이터·원문·열람 노트를 가리킨다. 주제/정서/유의어 사례의 골드는 확인한 양성 작품 집합이며 전 작품 관련성의 완전 판정은 아니다. 이 범주의 Recall은 확인한 양성 회수율로 표시하고 나머지 결과를 모두 오답으로 판정하지 않는다.

## 지표 계약

- 작품/근거 검색: 중복 ID를 처음 한 번만 세어 Recall@1/5/10, MRR을 계산한다. 근거는 source_id 기준으로 중복 청크를 합친다. 빈 골드는 Recall/MRR 집계에서 제외하고 `empty_correct`로 빈 결과 정확성을 별도 계산한다. 모든 빈 골드에서 결과가 없다고 Recall=1로 부풀리지 않는다.
- 조건 정확성: 실제 반환 항목 중 **명시적** author/year_kind/year_from/year_to를 모두 만족한 비율. 미확인 초출은 범위 통과 불가. 반환 0건은 null로 두며 ‘필터 정확도 100%’라고 하지 않는다. 누락은 Recall로 평가한다.
- 답변 의미 검토: 근거 충실성(주장 지지), 인용 정확성(번호 유효성과 주장/출처 연결), 충분성(최소 설명 요소), 근거 부족 처리 각각 0/1/2. 0=오류·근거 없음, 1=부분 충족, 2=충족. 검토자·이유·근거 위치를 남긴다. 번호 유효성 자동 검사를 의미 정확성 점수로 바꾸지 않는다. 미검토는 null이며 평균에서 제외·검토 건수 공개.
- 성능: 초기 색인과 질문 시간을 구분. 질문은 first/followup 및 검색어 추출·검색·선별·수집·색인·retrieve·generate·total 단계를 기록한다. n=1은 단일 측정으로만 표시하고 표본 없는 p95를 만들지 않는다.

## 인수 조건과 테스트

AC-B1: 고정 데이터의 ID 중복·작품/출처 참조·필수 범주·판정 항목을 오프라인 검증한다. 잘못된 작품 연결과 출처를 반례로 거부한다.

AC-B2: 지표는 예측 `[x,a,a,b]`, 골드 `[a,b]`에서 k=3 Recall=.5, MRR=.5이며 중복으로 점수가 증가하지 않는다. 빈 골드·빈 예측은 Recall/MRR=null, empty_correct=true. 잘못된 k를 거부한다.

AC-B3: 평가 세트·예시·보고서를 ingest하지 않는다. 현재 `load_documents`의 명시 입력만 유지하며 평가 파일을 추가해도 문서/청크 수·해시는 바뀌지 않는 회귀 테스트를 둔다. 실행 출력은 `evaluation/runs/`에 저장하고 Git 제외한다.

AC-B4: 비교 조건은 양쪽에 동일 제목·시인·시 전문, 동일 모델·동일 생성 옵션·독립 대화, 외부 해설 유무만 변경한다. 실제 러너는 #12에서 구현한다. MMR 기본값은 기존 similarity이며 #11에서 별도 구현한다.
