# 문예지 지면을 닮은 시담 — ISSUE #19

## 목적과 범위

개화기·일제강점기 시를 읽는 경험에 어울리는 문학적 화면을 만든다. 오래된 문예지의 활자·여백·괘선·인장색을 현대적인 독서 화면에 적용한다. 실제 역사적 판본을 복제하거나 특정 시집의 표지를 재현하지 않는다. 장식 문구는 서비스 안내이며 작가의 시구로 표시하지 않는다.

사용자가 요청한 디자인 개선이다. MVP 동작의 PRD 대응은 F2009(작품별 대화), F2010(구절 해설 카드), F2011(조건 탐색), F2012(상태·오류 안내)이다. 검색·연도·주제·출처·근거 격리·모델·색인·외부 수집은 기존 SPEC 그대로다.

## 시각 체계

- 바탕은 따뜻한 종이색 `#f5f1e8`, 지면은 `#fcfaf4`, 사이드바는 `#ebe6da`이다. 가는 괘선과 미세한 CSS 질감을 사용한다.
- 본문은 먹색 `#292d29`, 보조 글자는 `#62665d`, 포인트는 인주색 `#843f34`, 보조 장식은 짙은 초록 `#344b40`이다. 회색 미세 글씨·낮은 대비로 가독성을 떨어뜨리지 않는다.
- 제목·시 전문·대표 안내는 시스템 명조/바탕 계열을 우선하고, 입력·버튼·긴 해설은 읽기 쉬운 시스템 고딕을 쓴다. 웹 폰트를 다운로드하지 않으며 설치 폰트에 따른 자형 차이를 허용한다.
- 상단은 작은 시대/서비스 설명, 큰 서비스명과 문학적 소개, 인장 모티브, 수록 규모·이용 안내로 구성한다. 그림 대신 활자와 여백이 중심이다.
- 탐색 화면은 지면 제목·짧은 안내·기존 검색 폼·작품 카드로 구성한다. 검색 전에는 실제 작품에서 고른 소수의 읽기 진입 카드를 제공한다. 임의 추천 이유나 확인되지 않은 주제를 만들지 않는다.
- 독서 화면은 작품 제목/저자/연도 종류, 전문 지면, 질문·해설 영역으로 나눈다. 긴 전문의 스크롤과 모든 줄바꿈을 보존하며 좁은 화면에서 가로 넘침 없이 줄을 감싼다. 전문 문구·구두점·내용은 바꾸지 않는다.
- 사이드바는 작품 목록을 앞에 두고 색인·모델·청크·제외 자료 같은 운영 정보를 접힌 설정 영역에 둔다. 기본 similarity와 MMR 선택 기능은 보존한다.
- 대화의 답변·출처·시간·당시 검색 방식은 이전처럼 작품별로 유지한다. 시각 변경 때문에 이미 기록된 근거를 재생성하지 않는다.

## 접근성·안전

키보드 포커스를 보이게 한다. 색만으로 선택을 표시하지 않으며 버튼/입력의 실제 라벨을 유지한다. 모바일에서는 단일 열로 읽으며 사이드바를 다시 열 수 있어야 한다. Streamlit 메뉴·오류·사이드바 열기 조작을 전역으로 감추지 않는다.

HTML은 정적인 장식과 읽기 지면에 한정한다. 작품/저자/전문/동적 문자열은 `html.escape`로 이스케이프한다. 전문의 줄바꿈은 `white-space: pre-wrap`으로 보존한다. 생성 답변과 사용자 질문은 기존 Streamlit 렌더링 경로를 유지한다. 외부 이미지·스크립트·폰트·추적 요청을 추가하지 않는다.

## 인수 조건과 검증

| 조건 | 검증 |
| --- | --- |
| AC-D1 첫 화면에서 문학적 정체성과 작품 읽기 진입을 확인한다 | 실제 브라우저 첫 화면·작품 카드 선택 스크린샷 |
| AC-D2 전문·줄바꿈·제목·저자·연도 구분·출처·질문·구절 카드 유지 | AppTest 기존 선택 회귀 + HTML 이스케이프/줄바꿈 검사 + 실제 독서 화면 |
| AC-D3 빈 결과·키/색인 없음 안내·MMR·작품별 대화/출처 유지 | 기존 회귀 테스트, 실제 검색/질문/작품 전환 후 복원 |
| AC-D4 넓은 화면/좁은 화면 가로 넘침·포커스·대비 확인 | 브라우저 두 화면 크기, 주요 조작·스크린샷; 자동화가 불가능한 항목은 미확인으로 기록 |
| AC-D5 사용자/자료 텍스트의 HTML 실행 방지·추가 외부 자원 없음 | HTML 삽입 반례 Red→Green, CSS/템플릿 정적 검토 |

디자인을 그대로 베끼는 CSS 문자열 테스트는 만들지 않는다. HTML 렌더링이 추가되므로 실제 삽입 방지와 줄바꿈 보존을 검증하는 최소 테스트만 추가하고 기존 UI 회귀를 실행한다. SPEC 선커밋→Red→디자인 구현→Green/브라우저 확인→PR/CI→독립 리뷰→필수 검사·리뷰 통과 후 머지·ISSUE 종료를 따른다.
