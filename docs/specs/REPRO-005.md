# 다른 환경 재현 계약 — ISSUE #5

기준은 `rag_pjt.pdf`, `docs/SPEC.md`, `docs/specs/MVP-002.md`이며 F2001/F2002/F2005 및 NF2003/NF2004/NF2007의 배포 재현성을 보완한다. 기능·문학 품질 확장은 하지 않는다.

## 목표와 제외 범위

저장소의 동일 커밋에서 동일한 작품·근거 본문·출처·모델명·청킹 설정으로 초기 색인을 재생성한다. 개인 API 키와 외부 수집 연락처는 각 환경에서 별도로 설정한다. LLM 문구, 원격 모델의 내부 변경, 질문 이후 실시간 검색 결과, 개인 대화와 DB 파일의 바이트 일치는 목표가 아니다.

## 배포 자료

- 활성 100편과 기존 해설은 그대로 사용한다. 기존 `poem_metadata_100.*`를 혼합하지 않는다.
- 현재 위키 보조 자료 4개 파일을 포함한다. 문서·시인 맥락의 `context_only` 역할, 실제 열람 범위와 CC BY-SA 출처를 보존한다.
- 실행 중 성공 캐시에서는 허용된 공개 위키 문서 본문·출처 메타데이터만 `data/repro/public_documents.jsonl`로 고정한다. 검색어·질문·대화·연락처·API 키·접속 로그는 포함하지 않는다. 원문 URL·수집 시점·CC BY-SA와 변경 여부를 기록한다.
- 공개 스냅샷도 현재 권리 정책과 작품 ID를 다시 검사한다. 제목·시인·권리·역할·허용 필드가 잘못되면 거부한다. `(poem_id, source_id)`가 기존 자료와 겹치면 기존 큐레이션이 우선한다.
- `.env`, 로컬 Vector DB·수집 SQLite, 가상환경, HTML 캐시, 생성 답변, 이전 수집기·구 스키마·미완성 제출물은 배포 필수 자료가 아니다. 현재 사용자 변경을 포괄 커밋하지 않는다.

## 설치와 실행

- Python 3.12와 기존 PRD 고정 직접 의존성을 유지한다. Windows/Linux 조건을 포함한 해시 잠금 파일 `requirements.lock`을 제공한다. `pip install --require-hashes -r requirements.lock`으로 전이 의존성까지 설치한다.
- `.env.example`은 빈 GMS_KEY/WIKI_CONTACT와 공개 기본 모델·API 주소만 제공한다. 기존 `.env`를 덮어쓰지 않는다.
- 새 환경은 오프라인 자료 검사→키 설정→초기 색인→앱 실행 순서다. 공개 자료를 다시 크롤링하지 않아도 초기 상태를 만들 수 있어야 한다.
- `scripts/index_sidam.py --baseline`은 가변 실행 캐시를 제외하고 저장소 기준 자료만 색인한다. 기본 화면 갱신은 기존 캐시 재사용 계약을 유지한다. baseline 모드에서 모델·청킹이 기준과 다르면 색인 전 오류를 낸다.

## 재현 검사

- `data/repro/manifest.json`에 입력 파일 SHA-256, 작품/문서/청크 수, 정렬된 검색 텍스트·근거 청크의 내용/출처/권리 해시와 모델·설정을 기록한다. 현재 시각·절대 경로·개인 환경변수는 해시에 포함하지 않는다.
- `scripts/verify_repro.py`는 키·네트워크·기존 DB 없이 입력 변경·누락과 청크 기준을 검사하고 한국어 결과를 출력한다. 파일 변조, 누락, 정책 변경, 설정 변경은 실패해야 한다. 소스 갱신 시 검토 후 매니페스트를 명시적으로 다시 생성한다.
- 배포 소스의 키/연락처/개인 경로 및 금지 파일 포함 여부를 검사한다. 실제 `.env` 값과 일치하는 문자열은 업로드 대상에서 0건이어야 한다. 검사 로그에 값 자체를 출력하지 않는다.
- 깨끗한 별도 디렉터리·독립 가상환경에서 잠금 파일 설치, 오프라인 검증, 전체 테스트, 실제 GMS 초기 색인·검색·답변을 수행한다. 실제 실행에는 기존 사용자의 GMS 전송 승인을 적용하며 키는 프로세스 환경으로만 전달한다.
- CI는 Windows와 Linux에서 잠금 설치·오프라인 매니페스트 검사·키 없는 테스트를 수행한다. 유료 API를 CI 필수로 넣지 않는다.

## 인수 조건

R01: 원격 추적 파일만으로 동일 입력 해시와 작품/근거/청크 수.

R02: 비밀·개인 질문을 제외하고 공개 본문·출처·이용 조건 보존. 잘못된 스냅샷 거부와 권리 제외 반영.

R03: 잠금 의존성의 새 설치, pip check와 전체 테스트 성공. 키 없이 자료 열람·검사가 가능.

R04: 별도 폴더 실제 기준 색인·검색·답변 성공. 설정 불일치 시 시작 전 거부. 동일 재실행 중복 없음.

R05: 실행 문서·CI·독립 리뷰 완료 후 PR 머지, ISSUE 종료. 자료/문학 품질의 기존 한계는 유지하며 재현성과 혼동하지 않는다.
