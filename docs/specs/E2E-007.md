## 개선 후보의 현재 상태·우선순위

1. P0 벤치마크/판정 기준 선행: 현재 고정 평가 세트·평가지표 구현 없음. 기존 #4의 문학 품질·자료 결손과 연계하되 자료 69/98편 보완까지 완료했다고 하지 않는다.
2. P1 식별: 띄어쓰기/괄호 제거 일부 구현, 이름 등장만으로 저자를 판정하지 않도록 보완되어 있다. 이칭·본명·한자·판본 반례는 실제 자료와 테스트에서 재현 후 수정한다.
3. P1 성능: 단계별 시간 계측은 존재한다. P1 호출·수집·추가 색인·생성 비중을 실측하고 검증한 병목만 개선한다. 목표 수치 미확정 상태에서 NF2001 통과를 단정하지 않는다.
4. P2 F2014 MMR: 현재 유사도 검색만 있다. 후보 집합·lambda·예약 원문·poem_id 필터를 명시하고 같은 질문의 결과를 비교한다.
5. P2 F2015 품질 비교: 현재 별도 비교 러너/문서가 없다. 평가 데이터·허용 해석·필수 근거·금지 단정·실험 조건을 SPEC과 데이터로 먼저 커밋한다.

측정은 신규 실행의 전체·단계별 시간을 사용한다. 과거 3.42초·34초 등을 이번 서비스의 현재 응답 시간으로 재기록하지 않는다. 미구현·미검증·실패는 결과표에서 따로 구분한다.
